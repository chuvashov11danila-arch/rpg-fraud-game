# RPG Fraud Game — Конкурс «Охотник за фродом»

Интерактивный тренажёр в формате RPG-квеста для сотрудников отдела фотоидентификации МФО.

## 🎯 Цель проекта

Проверить и закрепить навыки сотрудников в выявлении мошеннических документов через игровой формат. Участник проходит кейсы, принимает решения и получает обратную связь с мемами.

## 🕹️ Как играть

1. Введи своё ФИО.
2. Тебе показывается кейс: фото документа + описание ситуации.
3. Выбери одно из трёх действий:
   - ✅ **Принять** — если паспорт действительный и не подделан.
   - ⚠️ **Недействительный** — если документ просрочен или данные не совпадают.
   - 🚫 **В ЧС** — если документ явно поддельный (фотошоп, фальшивка).
4. Получаешь обратную связь + мем.
5. У тебя 3 жизни. Если все потеряны — GAME OVER.

## 🛠️ Технологии

- **Python 3.10+**
- **Streamlit** — веб-интерфейс
- **PostgreSQL** — база данных кейсов и результатов
- **psycopg2** — подключение к БД
- **python-dotenv** — загрузка переменных окружения
- **Pillow** — обработка изображений (поворот фото)
